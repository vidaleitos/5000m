## 九、调整规则

### 每周判据（周日看）

| 指标 | 通过 |
|---|---|
| 周量 | 达标 ±3 km |
| 周一 6×1000 | 末组最快且达标 |
| 周三 6×6:00 | 末组不掉速 |
| 周六长跑 | 平均进 4:50，末 2 km 守住 |
| **恢复** | 周日不觉得需要休息两天 |

### 触发调整

| 信号 | 动作 |
|---|---|
| 轻松跑「感觉慢」+ 连续 10 天 | **过载信号 → 立刻减量 30%，不减课** |
| 周一课末组掉速 | 配速不动，间歇 2:00 → 2:15 |
| 周三课第 4 组掉速 | 减到 5 组，配速不动 |
| 长跑解耦 >6 s/km | 长跑加 2 km，配速降 5 s |
| 触地时间连续 3 周不动 | 力量内容错，不是量不够 |

### 每周只动一个变量

```
先动组数 → 再动配速 → 最后动量
```
