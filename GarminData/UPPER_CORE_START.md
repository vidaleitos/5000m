# 上肢 + 核心：执行手册

> v3 · 2026-10-01 重写。**按功能分组，用动作名，不用编号。**
> 系统逻辑见 UPPER_CORE_PROGRAM.md。
>
> **三种关系，每次看动作名旁边标的是哪种：**
> - **【替代】** 同一个刺激的不同实现 → **任选一个**
> - **【互补】** 各补一个刺激维度 → **都要做，合起来才等于一个完整的动作**
> - **【进阶】** 同一个动作的难度级别 → **按你的实际水平选一级**

# 块一 · 每天（12–14 分钟）

**挂点：跑完进门之前，或睡前。全部低负荷，不需要热身。**

## 活动度（4 件）

**胸椎后伸活动度 —— 30 秒 × 3**
仰卧，卷毛巾垫在**肩胛骨下缘**。双手抱头，**放松让上背沉下去**（不是压）。
往上移 2–3 cm 再做一组。
- **错**：腰开始拱起 → 位置太靠下，往上移

**胸小肌拉伸 —— 门框，30 秒 × 2/侧**
前臂贴门框、肘约 90°，同侧脚向前半步，身体前送。
- **错**：耸肩、憋气

**背阔肌拉伸 —— 30 秒 × 2**
跪姿，双手搭桌沿，手臂伸直，**臀部后坐、胸口下沉**。
- **错**：腰塌下去（不是腰在伸，是背在拉）

**靠墙天使·小幅度 —— 2 × 8–10**
背、臀、后脑贴墙。从 W 位（肘 90°）沿墙上滑到**你能保持下背贴墙的最大位置**，停 1 秒，回 W 位。
- **唯一判据**：腰是否离开墙。**一离开 = 超了 → 缩幅度，不是硬撑**
- 目的：逐步扩大"下背能贴墙"的范围

## 时间轴（3 件）⭐ 2026-10-01 新增

**这一组直接针对 65–70 分钟那个失效点。**
**原理**：跑步要的是 **90 分钟内保持正确肩胛位置的能力** —— 不是最大力量。
用 20–30 秒的组去练 90 分钟的保持，剂量是错配的。**所以必须有以分钟计的保持组。**

**肩胛后缩 + 下沉保持 —— 60–120 秒** ⭐ 最针对你的症状
站直或靠墙，双脚与肩同宽。**先后缩（往脊柱靠）→ 再下沉（往下压）→ 两个同时保持。**
想象把肩胛"塞进后裤袋并往下压住"。
- 肋骨下收、骨盆中立、**不憋气**
- **判据是位置不掉** —— 不是用力，是"撑得住"
- **顺带做那个测试**：一手摸脖子两侧（上斜方），看它是否比中下斜方先发力/更硬
  → 是 → **代偿阳性**（这就是区分"菱形肌/中斜方疲劳"和"上斜方代偿"的方法）
- **【进阶】** 60 → 90 → 120 秒 → 靠墙版（更难）→ 单腿站

**俯卧 Y 保持 —— 45–60 秒**
趴地，额头贴地。双臂摆成 Y 形（约 45° 上斜），抬起离地，**抬到位置后停住**，全程肩不耸。
- 主要练：中下斜方、后束、肩胛上旋
- **【进阶】** 加时间 → 手里捏 2 kg → 抬起后小幅度上下
- **【替代】** 与下面「墙面肩胛前伸保持」可交替 —— 两件都含肩胛前伸/上旋成分，
  但侧重不同（Y 偏后束和中下斜方，前伸偏前锯肌）。**时间紧时二选一。**

**墙面肩胛前伸保持 —— 30–45 秒**
面对墙，双手撑墙与肩同高。**主动把肩胛前伸**（身体远离墙）**并保持住。**
- 感觉在**腋下到肩胛外侧**
- **不是手臂在推，是肩胛在前伸的位置上撑住**
- **【替代】** 与「俯卧 Y 保持」可交替

## 摆臂（1 件）

**站姿摆臂·空手 —— 90 秒**
站直，躯干前倾 10°。手肘屈 90°，**锁在身体两侧的垂直平面内**。
前摆到**胸骨高度**，后摆到髋后，**不越中线**。肩保持下沉，**手放松不握拳**。
- 用余光检查手肘有没有往外跑

# 块二 · 每周 3 次（约 15 分钟）

**挂点：跑后（已经热了），或双课日的晚课之后。**

## 垂直拉的入口（1 件）

**部分悬挂（脚撑地）—— 3 × 20 秒**
公园横杆 / 门框单杠。**站在稳固的椅子或台阶上**，双手正握与肩同宽。
**脚不离地**，慢慢下蹲让手臂承受一部分体重。
- **标准**：没有任何牵扯感。**有感觉 → 站起来一点，让脚多分担**
- 这是在建立耐受，**不是练痛**
- **【进阶】** 站得更高 → 脚尖轻触 → 脚尖离地 → **完整悬挂（目标 60 秒）**
- **【替代】** 场地：公园横杆 / 门框单杠 / 树枝 / 任何能挂住的横向结构

## 拉的力（1 件 + 替代组）

**反式划船 —— 3 × 12**
**难度由身体角度决定**：脚踩地靠近锚点 = 身体陡 = 容易；脚往前伸 = 身体平 = 难。
**从最陡的开始。**
- **肩胛先动** —— 先收肩胛，再用肘把身体拉起来
- 拉到胸口接近锚点，停 1 秒，**慢放 2–3 秒**
- **错**：一上来就用肘拉 → 变成纯肱二头
- **【替代】场地（任选一个）**：桌子底下 / 公园低杆 / 门把手 + 毛巾 / 栏杆 / 树干横枝
- **【进阶】** 脚往前移 → 脚放椅子上 → 书包加重

## 后束 / 中斜方（1 件，两个替代）

**pull-apart（小环带）2 × 15** 或 **俯卧 T 抬 2 × 15**
- **【替代】** 二者任选 —— 同一批肌肉
- 环带幅度不够**没关系**：**刺激来自肩胛后缩，不是拉开的距离**
- **关键**：不是手臂在动，是**肩胛在动**
- 环带短到连起始位置都拉不开时 → 用**俯卧 T 抬 + 站姿肩胛后缩保持**

## 肩袖（2 件，互补）

**哑铃侧卧外旋（2 kg）—— 2 × 15/侧**
侧卧。肘部**贴住身体**（可夹卷毛巾防止肘跑开），肘屈 90°，前臂指向正前方。
以前臂为杠杆把哑铃往上转，停 1 秒慢回。
- **关键**：**肘不能离开身体**，上臂不能往后跑
- 2 kg 对肩袖足够 —— 这是小肌群
- **【进阶】** 慢离心 → 次数 → 更重哑铃

**站立等长外旋顶墙 —— 10 秒 × 3 个角度/侧**
侧对墙站立，**肘贴住身体**，前臂外侧顶住墙，往外旋方向推（等长）。
三个角度：前臂略朝前 / 正侧方 / 略朝后。
- **【互补】这两件的关系**：哑铃侧卧给**力量 + 离心**（侧卧位，肩胛有支撑）；
  站立等长给**站立位 + 肩胛稳定要求**。**两件都做才完整。**

## 前锯肌（1 件，两个替代）

**肩胛俯卧撑 —— 2 × 10**
俯卧撑姿势（撑不住就从跪姿或上斜开始）。**手臂伸直不弯。**
只让肩胛做动作：身体下沉（肩胛靠拢）→ 推起（肩胛分开、胸口远离地面）。
- **关键**：**手臂角度不变。** 手肘一弯就变成普通俯卧撑
- **【替代】** 肩胛俯卧撑 ↔ **俯卧撑+**（顶端多推一下让肩胛前伸）—— 二选一

# 块三 · 每周 2 次（约 10 分钟）

**挂点：跑后或睡前。**

## 起点（2026-09-29 修正）

**Fajir 有核心训练基础**（平板、侧平板、抬腿侧平板）。
所以下面每件都**从中间那级开始试**，用判据决定，不用我的表格决定。

**判据：能不能在「位置正确」的前提下完成 —— 不是能不能完成。**

| 动作 | 先试 | 稳就往上 | 不稳就往下 |
|---|---|---|---|
| 死虫 | **脚离地版** | 手脚同时伸出 → 负重 | 脚不离地 |
| 鸟狗式 | **肘膝相触** | 站立单腿版 | 停 3 秒基础版 |
| 侧平板 | **直腿** | 上侧腿抬起 → 髋部动态 | 跪姿 |

**你的核心缺口不在抗伸展和抗侧屈**（这两项有基础），**而在抗旋转、单侧负荷、负重、疲劳下控制。**

## 三向抗（3 件）

**鸟狗式 —— 2 × 6/侧**
四足跪姿。**收紧腹部** —— 不是吸肚子，是像准备被打一下那样。
伸出**对侧**的手和腿，**腿不超过髋的高度**，停 3 秒（想象背上放一杯水不能洒）。
- **关键**：**骨盆不能歪。** 宁可幅度小，也不要歪
- **【进阶】** 停 3 秒 → 停 5 秒 → **肘膝相触** → 站立单腿版

**侧平板 —— 2 × 20–45 秒/侧**
肘在肩正下方，前臂撑地。**髋顶起来，身体成一条直线。**
- **关键**：髋不能掉，也不能前倾
- **【进阶】** 跪姿 → **直腿** → 上侧腿抬起 → 上侧手伸直向上 → 髋部动态升降

**死虫 —— 2 × 8/侧**
仰卧，双手举起指向天花板，髋和膝各屈 90°。
**开始前先把手放在腰下确认贴地。** 慢慢伸出对侧的手和腿，**腰一旦离地就缩幅度**。
- **唯一判据**：腰一直贴地
- **【进阶】** 脚不离地 → **脚离地** → 手脚同时伸出 → 捏 2 kg 哑铃

## 抗旋转（4 件，互补）⭐ 一定要看这段

**这四件不是让你挑一个 —— 它们各补一个刺激维度，合起来才 ≈ 一个 Pallof press。**
**但一次做四件太多，所以：a + b 是基础，c 和 d 用来补缺口。**

| | 动作 | 剂量 | 补哪一维 |
|---|---|---|---|
| **a** | **哑铃单臂前平举抗旋** | 20–30 秒/侧 | 等长抗旋 + 站姿 |
| **b** | **单臂平板** | 20 秒/侧 | 抗旋 + 抗侧屈 |
| c | **自抗阻旋转** | 10–15 秒 × 3/侧 | **动态 + 旋转方向的力** |
| d | **推墙抗旋** | 15–20 秒/侧 | **水平方向的力** |

**为什么需要 c 和 d**：小环带太短、无把手、锚定麻烦 —— **做不了 Pallof press。**
而 a 和 b 缺的正是「动态的旋转力」和「水平方向的力」。c 和 d 就是补这两维的。

**做法：**

**a · 哑铃单臂前平举抗旋**
站姿，一手持 2 kg 哑铃，手臂前伸与肩同高。**哑铃会试图把躯干转走 —— 拒绝它。**
- **不是手臂在用力，是躯干在拒绝旋转**
- **【进阶】** 半跪姿（更不稳）→ 加时间 → 手臂伸更远

**b · 单臂平板**
标准平板姿势，**一只手抬起**（或只用一个肘支撑）。
- **【进阶】** 抬起的手脚同时对侧抬 → 加时间

**c · 自抗阻旋转**
坐姿或站姿，双手互握在胸前。**一只手试图把躯干往一边转，另一只手对抗它。**
慢速持续对抗。**身体不要真的转 —— 是对抗，不是移动。**

**d · 推墙抗旋**
侧对墙站立，单手推墙，身体往外倒一点，**对抗"被推转"的趋势。**

# 起步节奏

```
第 1 周  每天：活动度 4 件 + 站姿摆臂（摆臂只 60 秒）
               时间轴只做「肩胛后缩 + 下沉保持」，60 秒
         每周3次：只做 部分悬挂 + 反式划船，各 2 组
         每周2次：只做 鸟狗式 + 侧平板（按上表试起点）

第 2 周  时间轴加「俯卧 Y 保持」；每周3次加 pull-apart / T 抬 + 外旋两件 + 肩胛俯卧撑
第 3 周  时间轴加「墙面肩胛前伸保持」；核心补死虫 + 抗旋 a、b
第 4 周  抗旋加 c、d
```

**一次只加一个新动作**，观察 48 小时延迟酸痛。**上背最容易酸痛，而酸痛直接打击摆臂。**

# 现在不做

- **完整悬挂、引体** —— 会痛。等部分悬挂完全无感
- **过顶推** —— 等过顶活动度可用
- **任何到力竭的动作** —— 上背力竭打击 24–48 小时的摆臂
- **跑中刻意改摆臂** —— 活动度不够时强行改，只会产生新的代偿

# 零器械版（只有地面 + 墙）

**新增的时间轴三件全都是零器械的 —— 最重要的一维反而最不依赖器械。**

| 原版 | 零器械版 |
|---|---|
| 胸椎后伸（毛巾卷垫上背） | **四足跪姿，胸口往地面沉**；或**背靠墙角边缘后仰**（墙的边缘就是支点） |
| 背阔肌拉伸（跪姿手搭桌沿） | **四足跪姿手撑地，臀后坐、胸下沉** ← **完全等效** |
| 门框拉伸 / 靠墙天使 / 时间轴三件 / 摆臂 | **相同** |
| **部分悬挂** | **无等效替代** → 用「俯卧撑位肩胛下沉+撑起」覆盖下压的肌肉部分（方向相反） |
| **反式划船** | **四件组合**：俯卧直臂后伸 2×12 + 俯卧 T/Y/W 抬起 2×12/方向 + 毛巾自抗划船 2×12/侧 + 俯卧 W 抬起保持 30–45 秒 |
| pull-apart / T 抬 | **俯卧 T 抬**（本来就零器械） |
| 哑铃侧卧外旋 | **三件组合**：站立等长外旋顶墙（3 角度）+ 自抗阻外旋 15 次/侧 + 俯卧 T 拇指向上 2×12 |
| 肩胛俯卧撑 | **相同** |
| 核心全部 | **相同** |
| 哑铃单臂前平举抗旋 | **单腿站立 + 手臂前伸保持**；或**分腿站姿手臂画圈** |

## 零器械版补不了的三件事

| 补不了 | 后果 | 需要什么 |
|---|---|---|
| **牵引耐受** | 过顶/牵引能力**停滞** | 任何能挂住的横向结构 |
| **拉的力量** | **只能维持，不能显著进步** | 任何能抓住并离开的固定物 |
| **外旋的渐进负荷** | 停在某个水平 | 更重的哑铃，或带门锚的长管带 |

**后两项的解法是同一个：一条毛巾 + 一个能抓住的固定点。**
毛巾是**便携的抓握界面** —— 把门把、栏杆、柱子、树干全部变成可抓握的锚点。

**定位**：过渡 / 维持方案，不是长期等效。
**但在你最需要的那一维（时间轴 / 姿态耐力）上，它是满配的。**

# 验证

**主症状指标**：**长跑里肩胛酸出现的时间点。**
- 基线：**2026-10-01，后程 65–70 分钟**，位置肩胛骨后上（摆臂后摆区）
- 每 4 周记一次，看有没有往后推
- ⚠️ **它只能证明症状晚了 —— 不能单独证明竞技能力提高**

**能力节点**：部分悬挂秒数 · 反式划船次数 · 靠墙天使幅度 · 肩胛后缩保持秒数 · 摆臂时长

**跑步表现（关键层）**：@HR150 配速 · 长跑后 15 分钟的触地/步幅 · 3K/5K 计时

**每 4 周还要问两句**：
1. 这个能力是否仍值得占用训练资源？
2. 它是否正在解决真正的限制因素？

# 时间预算

```
每天 12–14 分钟 × 7  ≈ 90 分钟
每周3次 15 分钟 × 3  ≈ 45 分钟
每周2次 10 分钟 × 2  ≈ 20 分钟
合计 ≈ 每周 2.5 小时
```

**大部分是低负荷** —— 活动度、等长保持、核心。真正"上量"的只有 部分悬挂 / 反式划船 / 外旋 / 肩胛俯卧撑。

**如果它开始不发生：先砍活动度的组数，不要砍「肩胛后缩+下沉保持」。** 那一件针对你的症状最直接。
