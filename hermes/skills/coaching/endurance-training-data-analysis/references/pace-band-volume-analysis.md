# 配速带工作量分布

**用来回答"到底是哪里变了"的表。** 只用日志里已经有的两列：工作配速、工作总量。
它比周量、硬课数、强度分布都更能指出**变的是哪一段速度**。

---

## 为什么需要它（一个真实的序列）

跨时期比较里最容易犯的错，是把"练得少了"当成结论。本案的真实序列：

1. 周量同期对照：两年 86.74 vs 85.64 km → "没变"
2. 硬课数对照：主课从 6 堂变 7 堂 → "练得更多"
3. 心率分档配速：散布 ±10 s/km、符号还乱 → "这个方法测不出差异"
4. 但成绩估计从 2026-01 的 ~17:42 走到 2026-07 的 ~17:52 —— **确实停滞了**

周量正常、硬课数正常，成绩就是不动。
**原因不在"多少"，在"哪里" —— 而前三张表都看不见它。**

---

## 做法

```python
import datetime as dt

# 从日志读出：(日期, 工作总量m, 工作配速s/km)
recs = []
for r in range(2, ws.max_row + 1):
    d  = ws.cell(r, 1).value      # 日期
    st = ws.cell(r, 24).value     # 结构（空 = 不是质量课）
    wl = ws.cell(r, 25).value     # 工作总量 "8000 m / 32:56"
    wp = ws.cell(r, 26).value     # 工作配速 timedelta
    if not (d and st and wl and hasattr(wp, "total_seconds")):
        continue
    try:
        work_m = float(wl.split()[0])
    except ValueError:
        continue
    recs.append((d, work_m, wp.total_seconds()))

# 分带用绝对配速 —— 要回答的正是"他在哪些速度上投了量"
# 边界取整到分钟，否则同一堂课会随四舍五入在两期之间跳带
BANDS = [("快于比赛配速", 0, 217.0), ("比赛配速带", 217.0, 229.9),
         ("关键速度带", 230.0, 245.9), ("阈值带", 246.0, 255.9), ("慢于阈值", 256.0, 1e9)]

PERIODS = [(dt.datetime(2026, 2, 1), dt.datetime(2026, 4, 1)),
           (dt.datetime(2026, 4, 1), dt.datetime(2026, 6, 1)),
           (dt.datetime(2026, 6, 1), dt.datetime(2026, 8, 1)),
           (dt.datetime(2026, 8, 1), dt.datetime(2026, 10, 13))]

for a, b in PERIODS:
    sel = [x for x in recs if a <= x[0] < b]
    cells = [round(sum(w for _, w, p in sel if lo <= p < hi) / 1000, 1)
             for _, lo, hi in BANDS]
    print(f"{a:%y-%m} → {b:%y-%m}  ({len(sel):>2}堂)  {cells}")
```

**每个时期同时打印堂数。** 「堂数上升、而某一带的量塌掉」才是要看的信号 ——
只看总量会把这两种相反的事实混成一个数字。

## 实测（5000 m 运动员，5K PB 3:42.7/km）

| 时期 | 堂数 | ≤3:37 更快 | **3:38–3:49** | 3:50–4:05 | 4:06–4:15 | >4:16 |
|---|---|---|---|---|---|---|
| 25-12 → 26-02 | 10 | 16.5 | **8.5** | 16.6 | 6.4 | 13.0 |
| 26-02 → 26-04 | 15 | 12.3 | **61.0** | 24.2 | 0.0 | 3.6 |
| 26-04 → 26-06 | 16 | 42.9 | **57.3** | 14.0 | 0.0 | 0.0 |
| 26-06 → 26-08 | 15 | 9.0 | **39.3** | 0.0 | 0.0 | 39.0 |
| 26-08 → 26-10 | 28 | 19.6 | **8.1** | 0.3 | **32.1** | 26.6 |

（单位 km，全部是**工作总量**，不含热身冷身）

**读法：**

- 期间全部 PR —— 5K **18:33.7**（4/17）、mile **5:36.8**（6/9）、3K **10:37**（6/10）——
  都落在比赛配速带装量最多的两个时期（61.0 / 57.3 km）
- 8–10 月那一带只剩 **8.1 km**，而**阈值带从 0 涨到 32.1 km**
- **同期堂数从 15 涨到 28**

**结论只能写成：工作整体搬了一个配速带。** "练少了"和"练得更多"两种说法都被这张表否掉。

## 必须先过的关：露点

夏季那一带下滑，可能只是热，不是结构变化。**先按 §0 做露点匹配，再看这张表。**

本案能排除"下滑只是热"，靠的不是修正公式，而是：

> **同一个运动员在最热的 5–6 月（露点 16.1–20.4 ℃）仍然把 3:38.1–3:41.1 跑出来了。**

公式只能证明"热可能解释得通"，他自己的热天数据能证明"不是热"。**优先用后者。**

## 这张表不能告诉你什么

- **不能说哪一带导致了成绩变化。** 它是相关，不是因果。要定因果只能靠 N-of-1：
  把那一带的量单独放回去，看成绩动没动。汇报时要把这层说清，否则它会被引用成"因为缺了这一带，所以慢了"。
- **不能跳结构。** 工作配速必须**带恢复一起读**：同一个带里，"8 km 工作 + 长恢复"
  和"5 km 工作 + 短恢复"不是同一件事（`endurance-training-analysis` 的工作/恢复比）。
- **分带边界是人为的。** 换一组边界，相邻两带的量会互相流动。
  所以只读**跳时期的方向**，不要读单期某一带的绝对值，更不要拿它算百分比。
- **它不能替代判断。** 它把"哪里变了"指出来；"该不该改、改成什么"仍然是另一个问题。
