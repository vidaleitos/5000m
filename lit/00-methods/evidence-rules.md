# 文献 → 决定的规则

## 一、证据分级（本库自用）

| 级 | 含义 | 能不能单独支撑一个训练决定 |
|---|---|---|
| **A** | 系统综述 / meta，且人群接近（训练有素的耐力运动员） | 能 |
| **B** | 随机对照，n ≥ 20，训练有素 | 能，但要看剂量是否可外推 |
| **C** | 随机对照，n < 20 或人群为业余/未训练 | 只能做方向参考 |
| **D** | 横断面 / 观察 / 机制推测 | 不能，只能生成假设 |
| **E** | 教练经验 / 精英实践 | 能与 B 并列，不能取代 |

> **如果只有 C/D 级证据支持一条决定，就必须在计划里写明“这是推测”。**

## 二、适用性评分（`applicability`）

| 值 | 含义 |
|---|---|
| **high** | 训练有素的耐力运动员、剂量与我们要用的接近 |
| **medium** | 训练有素但项目不同（自行车/铁三），或剂量差一档 |
| **low** | 未训练人群、或剂量差两档以上 |
| **none** | 只说明机制，不能外推 |

## 三、一条文献落到一次训练上，必须回答四个问题

1. **它改变了哪个变量？**（配速 / 组数 / 间歇 / 频率 / 顺序 / 时长）
2. **剂量能不能外推？**（研究里是 6 周 3 次/周 —— 我们是每周 2 次，还成立吗）
3. **它的对照是什么？**（和“什么都不做”比，还是和“另一种训练”比）
4. **如果它是错的，训练会变成什么样？** ← **这一条不写，就不许引用**

## 四、反确认偏误的操作

**每次要引用一条文献支持某个已有决定时，强制做一次反向检索：**

```
搜索词 = 该结论 + "no effect" / "not" / "contrary" / "failed to"
```

**并把结果写进 `contradicting-evidence.md`，哪怕最后判定反证不成立。**

> **只找支持证据的检索，得到的不是证据，是修辞。**

## 五、人群外推的红线

**研究人群与他差距越大，结论越只能当假设：**

| 差距 | 处理 |
|---|---|
| 训练有素男性耐力运动员，20–30 岁 | 可直接用 |
| 训练有素但女性 / 年龄差 10 岁以上 | 方向可用，剂量打问号 |
| 未训练 / 肥胖 / 老年人 | **只能生成假设，不能定剂量** |
| 自行车 / 铁三 | 生理机制可用，**力学与经济性不可直接搬** |

**他：21 岁男性，181.5 cm / 65 kg，5K 18:05，周量 90–105 km，19 个月零伤停。**
**所以：自行车研究只能用于“心肺”，不能用于“跑步经济性”。**

## 六、置信度写法

```
confidence: A | B | C | D
applicability: high | medium | low | none
verified: true | false        # true = 在线核实过 DOI/PMC
```

**`verified: false` 的条目，可以讨论，不能进计划。**
